# Sable

The household ledger for African families and firms. Accounts, budgets, and receipts that keep wealth on the continent.

Source of the product rooms: [aiaugments-collab/finance-ai](https://github.com/aiaugments-collab/finance-ai).

## Run

```powershell
pnpm install
pnpm dev
```

No Docker. No Clerk. No paid keys. Any email and password opens `/dashboard`.

## House map

- `/` marketing
- `/product` `/team` `/about` `/contact` `/privacy` `/terms`
- `/login` `/signup`
- `/dashboard` in-app home
- `/account` `/transaction` `/budget` `/analytics` `/ai-assistant` `/receipt-scanner` `/ai-insights`

`pnpm build` is the host command.
